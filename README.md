# Обед вместе

Кликабельный мобильный прототип коллективного заказа обедов. Три связанных экрана: меню, мой заказ и кабинет поставщика. Все данные демонстрационные; приложение не принимает деньги, не создаёт реальные заказы и не отправляет сообщения.

## Запуск

Нужен Node.js 20 или новее. Устанавливать зависимости не требуется.

```sh
cd /Users/arch/projects/petProjects/lunch-together
npm run dev
```

Открыть `http://localhost:4173`. Для телефона в той же Wi-Fi сети использовать адрес `Network`, который напечатает сервер. Компьютер должен оставаться включённым, сервер — запущенным. Если порт занят, запустить `PORT=4174 npm run dev`.

Статическую папку `dist/` можно разместить на хостинге. Для работы прототипа не нужен сервер приложений или база данных. Настройка связанного приватного Sites находится в `.openai/hosting.json`.

## Как показать поставщику за две минуты

1. В «Меню» выбрать блюдо и количество. Нажать «Присоединиться», ввести имя. Сначала в заказе восемь вымышленных коллег; после записи будет девять участников.
2. В «Мой заказ» показать счётчик и закрытую до десяти участников оплату. Нажать «Демо: добавить участника».
3. Открыть демо-оплату, нажать «Смоделировать перевод». Денег и настоящих реквизитов здесь нет. Статус станет «На проверке».
4. Перейти в «Поставщику», найти свою строку и подтвердить поступление. Это отдельное действие: нажатие пользователя не считается оплатой.
5. Переключить демо-сценарий на «Собран». Это создаст десять оплаченных демонстрационных порций, сохранив выбранные пользователем блюда и не подтверждая за него оплату.
6. Показать сводку и нажать «Принять заказ в приготовление». После подтверждения изменения закрываются, в приготовление входят только оплаченные позиции.
7. Для повторного показа нажать «Сбросить демо» внизу кабинета поставщика.

Переключатели «Набор», «Оплата», «Собран» позволяют быстро показать разные этапы. Они меняют демонстрационные данные в текущем браузере. Сценарии «Набор» и «Оплата» сбрасывают статусы оплат; выбранные блюда сохраняются.

## Что заложено в прототип

- Минимум десять участников для открытия оплаты; минимум десять подтверждённых оплаченных порций для принятия заказа.
- Заявки до 10:30, оплата до 11:00, доставка 12:30–13:00. Это подписи демонстрационного расписания, а не серверные таймеры.
- Отдельные статусы «Не оплачено», «На проверке», «Оплата подтверждена».
- Сохранение демонстрационного состояния в localStorage, навигация по hash и работа кнопок «назад»/«вперёд».
- Копирование ссылки и итоговой сводки без автоматической отправки.
- Крупные кнопки для телефона, нижняя навигация, клавиатурный фокус, доступные модальные окна и reduced-motion.

Цена 1 100 ₸, меню на 20 октября, имена, отделы, офис и сведения о блюдах — примеры для показа. Фотографии иллюстрируют меню и не являются ассортиментом реального поставщика. Источники и лицензии: `dist/assets/SOURCES.md`, также доступны через «Авторы фото» в интерфейсе.

## Границы демо

Данные хранятся только в браузере: коллеги на разных телефонах не видят общий заказ. Ссылка приглашения открывает отдельную демонстрацию. Роли доступны без авторизации для удобства показа. Настоящих платежей, проверки переводов, уведомлений и интеграций нет. До рабочего пилота нужно договориться о недоборе, возвратах и правилах бонуса «10+1»; бонус в расчёты прототипа не включён.

## Файлы

- `dist/index.html` — оболочка и навигация.
- `dist/styles.css` — адаптивный интерфейс.
- `dist/app.js` — сценарии и состояние.
- `dist/assets/` — фотографии и иконка.
- `server.mjs` — локальный статический сервер.

Проверка синтаксиса: `npm run check`.
